# RAG 入門（廣東話）

RAG（檢索增強生成）嘅做法係：先喺你自己嘅文件入面搵相關段落，再將段落同問題一齊交畀語言模型，
等佢根據證據作答，而唔係淨靠記憶亂作。

## 切塊（Chunking）

切塊係 ingest 階段嘅工作，喺 embedding 之前完成。Embedding API 淨係收一段文字、傳回一個向量，
冇「chunk size」或者「overlap」呢啲參數，亦唔會幫你切長文件。切得太細會失去上下文，
切得太大又會令向量變得模糊。重疊（overlap）可以避免重要句子啱啱喺切口斷開。

## 向量庫

本示範用單一 SQLite 檔案加 sqlite-vec 擴充，儲存文字、來源同向量，用 cosine 距離搵最近嘅 k 個段落。
